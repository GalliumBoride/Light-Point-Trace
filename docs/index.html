怎么读这张图

  • 灰色点云: 光路成立时光射向的所有方向, 也就是弧可能出现的范围.
  • 彩色线: 区域的边界 (篱笆) 和最亮的边 (焦散). 颜色和下面的列表一一对应.
  • ●末端点: 弧在哪里结束 ●、在哪里折回 ▲、在哪里打尖 ✱.
  • 切到取向平面看同一件事在"晶体姿态"上的样子, 单击任一点看光路卡在哪一步.

图上的线

勾选一条线: 画出整条曲线 (淡色是延伸到光路不成立处的部分), 并用同色淡点铺出它的满足侧.
